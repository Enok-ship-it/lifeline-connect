# Lifeline Connect 🩸

**Lifeline Connect** is a responsive blood donation platform designed to bridge the gap between voluntary blood donors and individuals in urgent need. It provides a simple, fast, and reliable way to find life-saving blood donors in real time.

## 📋 Features
* **Donor Directory:** Browse and search for available blood donors sorted by blood type.
* **Urgent Requests:** A dedicated portal for patients or families to post immediate blood requirements.
* **Seamless Connectivity:** Quick options to contact donors directly when an emergency arises.
* **Responsive Design:** Optimized for smooth browsing on both mobile devices and desktops.

## 🛠️ Built With
* **HTML5** - Structuring the web pages and user forms.
* **CSS3** - Custom styling, modern layouts, and responsive elements.
* **JavaScript (ES6+)** - Handling interactive donor filtering, form validation, and application logic.

## 🚀 Getting Started

Follow these simple steps to run the website locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the project folder:**
   ```bash
   cd lifeline-connect
   ```
3. **Launch the app:**
   Simply double-click the `index.html` file to open it instantly in any web browser!
